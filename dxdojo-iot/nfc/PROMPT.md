# プロフィールページ生成プロンプト（コピペ用）

Claude / Gemini / ChatGPT のどれに投げてもOK。出てきた HTML を `index.html` として保存する。

```
名刺のNFCタグをかざすと開く、スマホ向けの1ページのプロフィールサイトを作ってください。
HTML 1ファイル（index.html）で完結、外部ライブラリなし、CSSは<style>にまとめる。

内容:
- 名前: ○○ ○○
- 肩書き: ○○株式会社 ○○
- 一言: 「○○が得意です」
- リンク（ボタン形式）: 会社HP / LinkedIn / X / メール
- 「連絡先をスマホに保存」ボタン（vCard形式を生成してダウンロード）

デザイン:
- スマホ画面幅で見やすく、ボタンは親指で押しやすい大きさ（高さ48px以上）
- 色は○○系（例: ネイビー×水色）
- 画像は使わない（イニシャルを丸で表示）
```

## 追加で頼むと良いもの
- 「英語版も切り替えられるように」
- 「ダークモード対応」
- 「QRコードも表示（このページ自身のURL）」
