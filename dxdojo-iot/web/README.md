# web/index.html — BLE 受信 ＋ スライド ＋ 傾き設定

Chrome / Edge で開く（Safari, Firefox は Web Bluetooth 非対応）。
`file://` でそのまま動く。動かない場合は `python3 -m http.server 8000` → http://localhost:8000/web/

## 機能
- 接続時にサービス一覧を取得し、UART があれば UART モード、なければ加速度計＋ボタンサービス（ACC モード）に自動切替
- 切断時は自動再接続（最大 20 回）
- 右上 **⚙ 傾き設定**（S キー）: 教え込み式の傾き判定
  - 基準姿勢を記録 → 右/左/前/後 それぞれの動きを記録 → 各方向にコマンドを割り当て
  - しきい値・待ち時間・なめらかさ（平滑化）をスライダーで調整
  - 設定は localStorage に自動保存。「初期設定に戻す」でリセット
- **Google Slides に転送** チェック（`chrome-extension/` を入れると表示）: このページではなく Google Slides のタブを操作
- L: 受信ログ ／ B: 暗転 ／ F: 全画面

## コマンド
| コマンド | 動作 | 既定の割り当て |
|---|---|---|
| NEXT | 次へ | 右 ／ B ボタン |
| PREV | 前へ | 左 ／ A ボタン |
| HOME | 先頭へ | 前 |
| BLACK | 暗転トグル | 後 |

## スライド内容の変更
`<section class="slide">` を増減するだけ。カウンターと進捗バーは自動。

## 判定ロジック（教え込み式）
基準姿勢からの差分ベクトル `delta` と、各方向に記録した単位ベクトルの内積を取り、
最大のものが `threshold` を超えたら発火。`threshold * 0.5` を下回るまで再発火しない（＋`cooldown` ms）。
取り付け向きが変わっても、基準と方向を記録し直すだけで対応できる。
