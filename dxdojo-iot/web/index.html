micro:bit × Web Bluetooth で
スライドを動かす

手に持った micro:bit を傾けるだけで、Chromeのスライドがめくれる。
ケーブルなし・アプリなし・ブラウザだけ。

▶ 右上の「micro:bit に接続」を押して、micro:bit を右に傾けてください

micro:bit は「右に傾いた」と判断したら NEXT という1行をBluetoothで送るだけ。
受け取る側は普通のWebページ。サーバーもアプリも要らない。

Web Bluetooth API とは

  • ブラウザのJavaScriptから BLEデバイスに直接 接続できる標準API
  • 対応: Chrome / Edge（PC・Android）。Safari / Firefox は非対応
  • セキュリティ上、ユーザーのクリックがないと接続ダイアログは出せない
  • https または localhost（ローカルファイルも可）でのみ動作
// たったこれだけで接続ダイアログが出る
const device = await navigator.bluetooth.requestDevice({
  filters: [{ namePrefix: "BBC micro:bit" }],
  optionalServices: [UART_SERVICE]
});

micro:bit 側：コードを書かない

  • 公式の 「BLE All Services」hex をUSBでコピーするだけ
  • 加速度計・ボタン・温度・LEDなど全センサーがBLEサービスとして公開される
  • ペアリング不要（Just Works不要）でChromeから即つながる
  • C++ビルド済みなので V1 でもメモリ不足にならない
// 判定はぜんぶブラウザ側
const x = view.getInt16(0, true); // milli-g
if (x >  500) nextSlide();
if (x < -500) prevSlide();
  • ⚠️ MakeCode + bluetooth拡張は V1 だと エラー020（メモリ不足） になりやすい
  • → 今回ハマった。ジェスチャーハンドラを減らしても足りなかった
  • 結論：センサーは公開するだけ、ロジックはブラウザが一番安定
  • hex: tech.microbit.org/bluetooth

ブラウザ側（受信して動かす）

const server  = await device.gatt.connect();
const service = await server.getPrimaryService(UART_SERVICE);
const tx      = await service.getCharacteristic(UART_TX); // micro:bit → PC
await tx.startNotifications();
tx.addEventListener("characteristicvaluechanged", e => {
  const text = new TextDecoder().decode(e.target.value);
  if (text.includes("NEXT")) nextSlide();
  if (text.includes("PREV")) prevSlide();
});

受け取った文字列で if するだけ。シリアル通信と同じ感覚で扱える。

つまずきポイント

  • 💾 MakeCode + Bluetooth は V1 で エラー020（メモリ不足） → 公式 All Services hex を使う
  • 🔑 MakeCodeで作る場合は No Pairing Required をONにしないと、見えても繋がらない
  • 🧭 接続ダイアログに出てこない → micro:bit を一度リセット／他のデバイスとの接続を切る
  • 🪟 Windows：OS側でBluetoothペアリング済みだと競合することがある → OSのペアリングは削除
  • 📦 1パケットは 20バイト。長い文字列は分割されて届くので改行で区切って組み立てる
  • 🔁 micro:bit に書き込み直すと接続が切れる → 「再接続」ボタンで復帰
  • 🧑‍💻 ページは https か localhost で開く。python3 -m http.server が手軽

応用例：センサー → ブラウザ → 業務

  • 🏭 温度・振動センサーの値をブラウザのダッシュボードに即表示
  • 🔘 物理ボタン1つで Power Automate のフローを起動（出退勤・在庫カウント）
  • 🧾 Copilot Studio のエージェントに「現場の状態」を渡す入口に
  • 📇 NFC名刺・電子ペーパー会議案内と組み合わせて「紙を減らす」導線
  • 🎓 子ども向けプログラミング教室の題材（傾けると動く！が一番ウケる）
  • 🧩 Chrome拡張を1つ足せば、同じ仕組みで Google Slides など既存SaaSも操作できる
  • 💡 ポイント：特別なアプリを配らなくていい。URLを開けば使える

まとめ

傾ける → 送る → 受ける

  • micro:bit は約2,500円。Bluetooth・加速度・ボタン・LED 全部入り
  • Web Bluetooth で「ブラウザ＝IoTの受け口」になる
  • 難しいのは通信ではなく、ペアリング設定と20バイト制限の2つだけ
